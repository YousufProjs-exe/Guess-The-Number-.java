# Guess-The-Number-.java
This Java console game utilizes Scanner for user input. It generates a random number (1-100) that players try to guess within a loop. Conditional logic provides "too high" or "too low" hints after each attempt. The game concludes when the user guesses correctly. Its an ideal project for practicing core Java concepts like Scanner and Random classes.
